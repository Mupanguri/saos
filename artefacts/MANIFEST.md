## Verify integrity

```powershell
# Compare every file against this manifest
Get-Content MANIFEST.csv | ConvertFrom-Csv | ForEach-Object {
    $p = Join-Path $PWD $_.path
    if (-not (Test-Path $p)) { "MISSING  $($_.path)"; return }
    $h = (Get-FileHash $p -Algorithm SHA256).Hash.ToLower()
    if ($h -eq $_.sha256) { "OK       $($_.path)" } else { "CHANGED  $($_.path)" }
}
```

A `CHANGED` line on a delivered file means it is no longer the artefact that was
reviewed. A `MISSING` line means the set is incomplete.

## Canonical source

The control library in `06-source/library/` is the source of truth. Everything
marked *generated* above is produced from it by `build/build_workbook.py` or
`03-library/export_library.py`. Never edit generated files — edit the YAML and
rebuild. `control-catalogue.json` additionally embeds the SHA-256 of each source
YAML file, so any catalogue export is traceable to the exact library snapshot that
produced it.
